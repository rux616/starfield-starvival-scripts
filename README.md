# Starvival Script Sources
Contains the script sources for the Starfield mod "Starvival". Intended to be used as a submodule.

Actual mod lives on [Nexus Mods](https://www.nexusmods.com/starfield/mods/6890) and on [Creations](https://creations.bethesda.net/en/starfield/details/cb70aedd-4793-4e05-be51-b5a4987d6b71/Starvival___Immersive_Survival_Addon).
